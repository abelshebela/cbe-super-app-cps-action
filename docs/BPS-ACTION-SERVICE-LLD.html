1. Executive Summary

The BPS Action Service (also known as cps-action-service) is the central orchestration engine for the CBE Super App's administrative operations. It implements a robust Maker-Checker workflow pattern to ensure security, accountability, and dual control for sensitive system actions.

This service acts as a middleware layer that intercepts administrative requests, enforces approval workflows, and dispatches approved actions to their respective downstream services (Bank Service, User Service, etc.).

1.1 Key Capabilities

  • Maker-Checker Workflow: Enforces dual control for critical actions (Create, Update, Delete, Enable/Disable).
  • Action Dispatching: Routes approved actions to 30+ different domain services.
  • Audit Trail: Maintains a comprehensive history of all actions, including maker, checker, timestamps, and changes.
  • Security: Integrates with JWT authentication and role-based access control (RBAC).
  • Scalability: Built on a microservices architecture using Go, MongoDB, and Kafka.

2. Service Overview

2.1 Business Context

In the CBE Super App ecosystem, administrative actions (like creating a new bank, blocking a user, or updating a transaction limit) carry significant risk. The BPS Action Service mitigates this risk by ensuring no single user can perform these actions unilaterally.
